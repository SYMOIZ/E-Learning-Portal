# Workflow Diagram Breakdown: Control Flow

## Student Workflow

```mermaid
flowchart LR
    A[Input or Idea] --> B[Apply Conditional Statements]
    B --> C[Apply For Loops]
    C --> D[Apply While Loops]
    D --> E[Result]
    E --> F[Explain Result]
```

## Diagram Reading Questions

- What is the first step?
- What changes in the middle step?
- What output or result should appear at the end?
