1. Sample answer: What is the difference between a class and an object? A strong answer defines the idea, gives one example, and mentions one mistake to avoid.

## Coding Task Guidance

- Beginner task: your code should run without syntax errors.
- Intermediate task: your changed data should produce a changed result.
- Advanced task: your comments should explain why the code exists, not only what each symbol means.

## Mastery Signal

You are ready to move on when you can explain the topic, run the examples, answer the questions, and fix one intentional error.
