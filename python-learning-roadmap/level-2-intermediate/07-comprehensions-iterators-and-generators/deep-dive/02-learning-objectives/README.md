# Learning Objectives Breakdown: Comprehensions, Iterators, and Generators

## Skill Targets

- Define the topic in one or two clear sentences.
- Recognize the topic in existing Python code.
- Write a small example from memory.
- Explain one real-world use case.

## Student Success Rubric

| Level | Evidence |
| --- | --- |
| Beginning | Can identify the topic when shown code. |
| Developing | Can modify a provided example correctly. |
| Proficient | Can write a new example without copying. |
| Advanced | Can explain tradeoffs, mistakes, and best practices. |

## Checkpoint Question

What output or behavior proves that your code works?
